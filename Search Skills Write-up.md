# Search Skills

## Overview

The **Search Skills** room introduces one of the most important abilities in cybersecurity: knowing **how to find accurate technical information efficiently**.

Cybersecurity professionals constantly research vulnerabilities, malware, operating systems, software documentation, and attack techniques. Rather than memorizing everything, they develop strong research skills using trusted search engines, security platforms, technical documentation, and open-source resources.

This room covered how to use specialized cybersecurity search tools, vulnerability databases, Linux documentation, and GitHub to solve technical problems more efficiently.

## 3. Shodan

### What is Shodan?

Shodan is a search engine for internet-connected devices.

Unlike Google, which indexes websites, Shodan indexes:

- Servers
- Routers
- Webcams
- Industrial control systems
- IoT devices
- Firewalls
- Public services

### Why It Matters

Security professionals use Shodan to:

- Discover exposed assets
- Audit public infrastructure
- Identify vulnerable services
- Understand attack surfaces

---

## 4. VirusTotal

### What is VirusTotal?

VirusTotal is an online malware analysis platform that scans:

- Files
- URLs
- Domains
- IP addresses
- File hashes

using dozens of antivirus engines and threat intelligence feeds.

### Why It Matters

VirusTotal helps analysts:

- Investigate suspicious files
- Check URL reputation
- Validate Indicators of Compromise (IOCs)
- Research malware
- Support incident response

---

## 5. Vulnerability Databases (CVE)

### What is CVE?

Common Vulnerabilities and Exposures (CVE) is a standardized catalog of publicly disclosed security vulnerabilities.

Each vulnerability receives a unique identifier.

Example:

```text
CVE-2024-3094
```

### Why It Matters

CVE databases help professionals:

- Research vulnerabilities
- Understand affected software
- Prioritize patching
- Study exploit details
- Improve vulnerability management

---

## 6. Technical Documentation (man Pages)

Linux systems provide built-in documentation using the `man` command.

Examples:

```bash
man ls
```

```bash
man grep
```

Manual pages explain:

- Command syntax
- Available options
- Examples
- Usage

Reading official documentation is one of the fastest ways to solve Linux problems.

---

## 7. GitHub

GitHub is much more than a code hosting platform.

It is one of the largest cybersecurity knowledge bases available.

Professionals use GitHub to:

- Publish security tools
- Share writeups
- Learn scripting
- Study open-source projects
- Discover proof-of-concept exploits
- Build professional portfolios

Maintaining an active GitHub profile demonstrates technical growth and continuous learning.
